# Smart-Chromatic-Shape-Sorting-System-Using-PLC-Automation
Smart Chromatic &amp; Shape Sorting System using PLC Automation. This project uses a Delta PLC, infrared sensors, OpenCV computer vision, and Arduino communication to detect and sort objects by color and shape, demonstrating industrial automation and intelligent manufacturing.
